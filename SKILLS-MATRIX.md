# Automation Skills Matrix

| Area | Demonstration |
|---|---|
| PowerShell | Windows and Active Directory administration workflows |
| Python | Linux operations, log analysis and reporting components |
| Active Directory | Repeatable account lifecycle workflow |
| Windows Operations | Patching, Event Logs and system health |
| Linux Operations | Package-management automation concepts |
| Monitoring | CPU, memory, disk and service health collection |
| Reporting | Aggregation of operational information |
| Troubleshooting | Event/log driven investigation rather than guesswork |

## Engineering Principles
- Prefer repeatable automation over undocumented manual steps.
- Validate inputs before administrative changes.
- Produce useful output for verification and troubleshooting.
- Keep platform-specific logic understandable.
- Test privileged automation in a lab before production use.
