# Interview Guide — AutoSysAdmin

## 30-Second Explanation
AutoSysAdmin is my systems-automation project using PowerShell and Python. It focuses on repetitive IT operations such as Active Directory account lifecycle, Windows and Linux patching, Event Log analysis and system-health reporting. The goal is to show how I move from manual administration toward consistent and auditable automation.

## Topics I Can Explain
- Why PowerShell is useful for Windows and Active Directory administration.
- Why bulk user operations should validate source data.
- How automation reduces repetitive work but can increase risk if not tested.
- What system-health information is useful during troubleshooting.
- How Windows Event Logs help diagnose authentication and system issues.
- Why patch automation needs verification and reporting.
- Why administrative scripts should be tested in a controlled environment.
